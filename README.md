# Planora

Planora, günlük görevleri, notları, hatırlatıcıları ve kişisel listeleri tek bir platform üzerinden yönetmeyi amaçlayan kişisel üretkenlik uygulamasıdır.

Proje kapsamında görev yönetimi, özelleştirilebilir hatırlatıcılar, not sistemi, kitap ve film takibi gibi özelliklerin yanı sıra ilerleyen aşamalarda **AI destekli planlama ve öneri sistemi** geliştirilmesi hedeflenmektedir.

## 🛠️ Teknolojiler

* React
* JavaScript
* Spring Boot
* PostgreSQL
* REST API

## 🚀 Planlanan Geliştirmeler

* AI Assistant
* Bildirim sistemi
* Docker
* AWS deployment
* React Native mobil uygulama
